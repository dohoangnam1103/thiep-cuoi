# i18n audit — 2026-08-31

## Findings and fixes

1. `/admin/demos/[id]` supplied only `editor` messages to `EditorForm`. Its preview renders `ChungDoiDemo`, which also needs the invitation namespaces. `/editor` likewise supplied only editor, countdown and footer messages. Both now use `editorMessageNamespaces`, shared with the admin support editor.
2. The audited renderer branch inside `ChungDoiDemo` installed a nested provider containing only `invitationTemplate`. This discarded sibling namespaces, including `comicHero`, even when the route supplied them correctly. Removed this redundant provider; renderers inherit the complete route payload.
3. `selectMessages` now rejects missing, null/undefined and inherited namespace properties instead of silently accepting unusable payloads.

The `invitationTemplate.invitedToWedding` key exists in the Vietnamese catalog. This incident was a provider/payload defect, not missing copy. Existing editorial English in template copy was not rewritten.
