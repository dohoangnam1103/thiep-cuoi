# Editor2 gift setup hint — 2026-10-28

## Scope and corrected placement

When neither person has a usable bank/account-number pair, show “Điền thông tin ngân hàng để nhận quà mừng từ bạn bè và người thân.” in the existing completion suggestions below the invitation, outside `[data-editor2-inline]` and the template renderer. The owner clarified that this is editor guidance and must not appear under the envelope inside the invitation.

The suggestion opens the gift form by pointer or keyboard, remains for partial input, and disappears when an account is usable or the editor switches to guest preview.

## Implementation contract

- Route: `/editor2/[id]`; section: existing `.e2-suggestions`, after the invitation.
- Existing data: bride/groom bank name, account number, account name; `editor2MissingSections` and VietQR validation continue to determine missing setup.
- `Editor2InvitationPreview` includes gift in its existing missing-section suggestions, using `editor2.giftSetupHint` in `messages/vi.json` as the button text.
- `Editor2GiftPlaceholder` continues to offer the existing editable envelope for templates without a native gift. It no longer inserts guidance into any template or native gift container.
- The suggestion uses the editor's existing button, focus, palette and responsive wrapping styles. It is outside the canvas capture handler and keeps native click/keyboard behavior.
- Existing envelope artwork, containing blocks, headings, template palette, typography, sections and responsive layouts remain unchanged. No new assets, fields, schema, API, URL, ownership, persistence or publication changes.

## Acceptance and evidence

The focused cases cover Song Hy and Double Dragon at 1440 and 390 pixels: exactly one hint in the completion suggestions, no hint inside the invitation, suggestion bounding box below the invitation, pointer/keyboard activation, empty/partial/complete account states, save/reload, guest mode, no fabricated second account and no horizontal overflow or page errors. Catalog-wide checks assert the hint is in `.e2-suggestions` and absent from `[data-editor2-inline]` for every completed template at desktop/mobile widths.
